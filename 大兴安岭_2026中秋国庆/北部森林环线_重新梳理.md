## 用户新提议

北京 → 海拉尔 → 莫尔格勒河 → 额尔古纳 → 根河 → 满归 → 伊克萨玛 → 奇乾 → 白鹿岛 → 临江 → 室韦 → 卡线 → 黑山头 → 满洲里 → 湖区 → 阿尔山 → 北京。

整体方向成立：先向北进入森林，再顺界河南下，经边城、湖泊回阿尔山，景观由草原河曲、森林河谷、村落界河到火山湖过渡。满归等点按最新请求重新比较，不能继续沿用旧版“不去满归”作为用户当前决定。难点集中在北部穿越的合法通行、充电冗余、气候和13天余量，而不是简单把地图上的点连起来。

## 两种北段走法

### A：满归—伊克萨玛穿越方案（用户原设想）

根河 → 金河/阿龙山方向 → 满归 → 伊克萨玛 → 经获准通行的连接道路到白鹿岛/奇乾方向 → 临江。

优势是能看满归林业小镇与伊克萨玛森林河谷，若连接通道合法畅通，形状更接近环线。

问题：没有核实2026年本次出行日允许普通游客自驾贯穿伊克萨玛至奇乾/白鹿岛的官方依据。2024—2025游客与商家记录互相矛盾，有走通记录，也有被劝返记录。入公园、进入北部原始林区、进入奇乾村和过境到另一端是四件事，不能互相替代。严禁用骑行导航绕开汽车限制、绕卡或把地图不显示的林道当成常规自驾路线。

奇乾先按需核准准入的支线目的地处理，不将穿村当作连通白鹿岛的必经捷径；其与白鹿岛的实际访问顺序取决于获准入口，允许支线往返。

若连接通道不允许走，满归返回根河方向再转根白线将产生明显折返。不是“再多开几十公里”就解决，也不能临时改走金河—莫尔道嘎S302封闭段。

此方案建议按14—15天级别重新核算游览与退路余量；不是物理上绝对无法压进13天，而是13天若全部保留，往往必须牺牲停留、返程缓冲或依赖未确认近路。加天数也不能替代准入与充电确认。

### B：根白线—莫尔道嘎—白鹿岛方案（13天更推荐）

根河 → X325根白公路 → 莫尔道嘎镇 → 白鹿岛 →（奇乾条件支线）→ 临江 → 室韦。

本方案建议不绕满归、伊克萨玛，把有限时间留给森林河流景观；这是建议取舍，并非用户已确认删除这两处。

需要区别：

1. **根白公路**是根河前往莫尔道嘎/白鹿岛方向的道路走廊。
2. **莫尔道嘎国家森林公园园内游览道路**是景区经营和管理体系，不能等同于根白公路，不能默认过路必须买票，也不能默认买票后车辆和两犬都能贯穿。
3. **白鹿岛及其观景点**也要核实入口、营业、驾车通行与携犬要求。文旅介绍能证明景观存在，不能证明当天可进入。

具体倾向：优先确认合法开放的根白方向道路和白鹿岛观景；只有公园允许你们车辆及两只成年边牧同行、当日时间也合适，才加入园内穿行。若不能携犬，不安排留狗在车里等人进入。当前不能把某条外围道路直接标成“免费可走”，也不承诺任意门进出。

## 官方已核的关键限制

- 根河交通局2026-04-08公告：S302金河—莫尔道嘎K0+000—K18+200，2026-04-08至2026-10-30封闭。公告绕行是金河→S204→根河→X325→莫尔道嘎。适用本次日期；仅据此判断公告区段，不扩写为整条S302全部封闭。
- 黑山头—室韦卡线有2026养护预公告转载，计划5月下旬至7月初施工，给出的替代是G331。尚未查到此次9月底/10月初恢复通行的充分确认；不能把预计完工当实际恢复。
- 北上G5511查草段资料有矛盾：早期资料描述主线贯通，2026-09-20报道仍称交工筹备、年内通车可期。故不宣称全线高速已畅通，必须另核实际开放道路和衔接。工程贯通不等于已开放运营。

## 湖区如何取舍

默认将“满洲里边上的湖区”理解为呼伦湖；如果用户还想去贝尔湖，需要单独比较入口、边境规则、往返支线和补能，不把两个湖当成顺路同一处。满洲里到阿尔山这天只选一个湖泊观景停点，不走非法岸线或湿地便道。

## 电车、两犬与季节

- 根河、莫尔道嘎、满归及边境乡村的快充不能凭地名推断存在，更不能把“营地水电齐全”当成可给汽车充电。北部具体主站/独立备站、营业、进出电量尚未逐项核实。
- 核算从最后可靠充电点出发，经森林观景和住宿，到下一可靠充电点的完整区间，包含取暖、低温、支线往返及被劝返的电量。不能只算单程抵达奇乾。
- 本轮不新增狗证件清单；奇乾等地道路/边境准入与狗证件不是同一件事。景区、住宿须确认两只成年边牧，野生动物和驯鹿项目不默认适合带犬。
- 白鹿岛的河曲岛屿、奇乾的界河村落、阿尔山的火山湖具有非秋叶价值；满归/伊克萨玛的林业小镇与森林河谷也有独立内容，但与根白/莫尔道嘎森林体验重叠更多，13天中应优先比较单位时间所得，而非因“不去漠河”就认定满归绝对不值。
- 不保证浓秋、晨雾、初雪、日落、观景点开放或“没游客”。季节提前看北部、再南下阿尔山是排程考虑，不是景色保证。
