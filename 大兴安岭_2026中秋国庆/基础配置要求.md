## 3. 行驶节奏与道路选择

- 赶路日以效率为先，可以安排较长高速里程，不强行平均成每天400—500km。
- 初稿高速转场通常约600—850km/日，必须把充电、吃饭、遛狗、拥堵加进总耗时；这只是排程区间，不是每天必须达到的指标。
- 林区游玩通常约150—350km/日；超过400km的林道转场单独标记强度，减少停点并准备拆日。
- 每约2小时合并停车、遛狗、补水和充电。未知林路和非铺装连接线安排白天通过。
- 道路对照必须包含：高速/国省道比例、大车评价、施工与坑洼、信号、补给、秋季开放情况以及替代线的实际代价。
- 优先铺装、可通行、补能有依据的公路。货车评价用于比较，不把高速默认写成“货车少”，也不为避货车自动切入更差的小路。
- V0.3去程北京—通辽—乌兰浩特—阿尔山压缩为两天；不再住锡林浩特/霍林郭勒。北部尽量环游，返程经牙克石、乌兰浩特向承德/北京推进。
- 效率、安全、可靠补能优先于“零重复”；允许南部高速、海拉尔附近主路、柴河进出与卡线绕行重复。原“西进东出、基本零折返”的图示不再用于本版。
- D12承德是条件目标，预计总行程不超过约12小时且状态良好才继续；否则停赤峰或途中已核点位。D13根据实际落脚地重算，不加景点。疲劳时立即缩短，不等到时限。

## 4. 充电配置：沿用详细点位＋主备方案

每个补能段必须给出：

| 字段 | 必须达到的粒度 |
|---|---|
| 点位 | 正式站名、地址/服务区、道路编号、行驶方向、导航链接 |
| 设施 | 运营商、直流/交流、公开功率和枪数；查不到就标未核，不补造数据 |
| 能耗 | 分段公里数、预计到站SOC范围、充至目标SOC、估计充电时间 |
| 备选 | 主站＋备选A/B，说明前置/后置位置和是否需下高速 |
| 切换 | 排队、不可启动、天气或到站SOC不足时，在哪个点改变计划 |
| 证据 | 来源、核验日期；区分“建成”“运营”“当时能充”和“出发当天能充” |

- 赶路主充优先同方向高速服务区，吃饭/卫生间/遛狗合并；进出城或落地补能可用城区站。
- 林区没有高速服务区时，以已核实的县城/镇上站为基础，不凭空指定高速桩。
- 常规目标85—90%；稀疏补能段可在出发前充95—100%，按实际需要决定。
- 一般到下一已核实补能点保留至少20%，寒冷/稀疏段初稿按25—30%余量评估。均是规划门槛，不是实测结果。
- 排队超过20分钟考虑切站，先确认备选可达且余量满足；不因一个“备选”名字就默认能跳过主站。
- 北方秋季低温、暖风、逆风、冷电池及车宿耗电另算；不套用新疆夏季SOC，也不写“下坡足以回满”。
- 最终电量表结合这辆车近期实际高速电耗、可用电池容量、负载和车机预测；当前信息不足，不生成假精确SOC。
- 两家不同地址的桩群才算不同站；同一桩群内两个枪头不能当两份独立备选。
- 某林段找不到足够可达备选时，明确缺口，缩短/拆分该段或取消，而不是把“某镇公共站”写成已落实。

## 5. 住宿与车宿

- 继承舒适型偏好，酒店/民宿基础目标300—600元/晚；国庆实时价格另核，原新疆总预算不直接搬用。
- 用户确认游玩日住宠物友好酒店/民宿，赶路日可在高速服务区车宿。12晚中两者比例未锁定，随具体落脚点、低温条件和车内布局细分。
- “宠物友好”须细化到两只成年边牧：数量、体型、费用、押金、可进入区域、停车和是否要求额外材料。
- 酒店给出正式名称、地址、电话、预订入口、主备店和实际确认状态；原新疆店名/电话不迁入新清单。
- 服务区给出具体名称和方向侧、普通小车夜间停车区、厕所、补能点以及未能停留时的替代点。
- 充后移车，充电车位不作整夜住宿位；林区车宿要核对暖风耗电与次日余量。
- 本次车宿按夫妻＋双犬配置准备，睡眠布局需适配两人两犬；不直接复制新疆后半程的一人两犬布置。
- 寒冷、补电无法落实或车内睡眠不合适时，转为酒店夜；不把野外林间空地当现成营地。

## 6. 吃饭、游玩与秋季适配

- 餐饮继续采用大众点评65%、携程35%的双源参考，先匹配同一家门店并统一量纲；缺少一方评分就标单源，不伪造加权总分。
- 每日餐饮包含店名、位置、评分来源/日期、样本量、推荐菜、预算、顺路程度和两犬就餐办法。
- 赶路日不为网红店专门下高速；景观日选择顺路、口碑可靠的本地餐厅。宠物无法同处就外带到允许停留的地点。
- 林海、湿地、河谷、公路风景和小镇为优先候选；驯鹿接触、小火车、区间车和需进入核心区的项目单独核实两犬条件。
- 不沿用新疆8月“早10点前/晚7点后”的避热时间。东北秋季以当日日出日落、低温与路面状态安排户外。
- 秋色、初雪和天气按最近发布的信息更新；不能用旧年份最佳观赏日保证今年某天的景色。
- 林区开放/防火公告与道路状态属于路线核验内容。只走允许通行和停车的区域，不依赖野炊、穿林或临时野路拍照。

## 7. 不继承的新疆专属内容

28天时长、8月日期、18晚酒店＋9晚车宿、D16送机、成都/武汉会友、指定新疆酒店、S240/S245必走、大海道/禾木/赛湖/独库的准入确认、夏季电耗、当地施工公告、旧总预算全部留在归档。大兴安岭不继承任何当地商家的“已确认”状态。
