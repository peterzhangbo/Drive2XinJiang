## 已确认

- 9月25日—10月7日，9月28—30日请假3天。
- 夫妻二人＋两只成年边牧，Model Y L北京往返。
- 游玩日住宠物友好酒店，赶路日可睡服务区；赶路补能优先同方向高速服务区。
- 漠河/北极村/满归不去，白鹿岛不进主线。秋色是加分项，保留火山河谷、边城和村落。
- 去程北京→通辽→乌兰浩特→阿尔山两天，取消锡林浩特/霍林郭勒过渡夜；省出一天给室韦—恩和。
- 北部：阿尔山→柴河（条件支线）→海拉尔→满洲里→黑山头→室韦→恩和→额尔古纳→海拉尔方向→牙克石。
- 南返：牙克石→乌兰浩特→承德方向→北京。D12不满足驾驶状态和约12小时全天门槛时停赤峰，D13不加景点。
- 主路允许必要重复；柴河—塔尔气与边境卡线不默认畅通。
